Las 7 variantes oficiales
01 — Imagotipo Full
Versión completa: isotipo + wordmark + línea separadora + tagline "EFFICIENCY GROWTH". Usar para propuestas comerciales, documentos institucionales y presentaciones formales.
Propuestas Institucional Documentos formales No usar en tamaño reducido
02 — Imagotipo
Isotipo + wordmark. Versión principal para uso digital, web y RRSS. Sobre fondo blanco.
Web RRSS Email
03 — Logotipo
Solo el wordmark "Bleads". Para fondos de color corporativo donde el isotipo pierde legibilidad.
Fondo azul Fondo rojo
04 — Isotipo full (lobo+luna)
Ícono completo: silueta del lobo sobre círculo rojo. Para avatar, favicon y usos donde el espacio es reducido.
Avatar Favicon App icon
05 — Isotipo simple (lobo)
Solo la silueta del lobo sin el círculo rojo. Elemento gráfico más versátil, puede usarse como decoración o watermark.
Decorativo Watermark
06 — Imagotipo blanco (luna roja)
Versión negativa. Lobo blanco sobre luna roja, texto blanco. Para fondos oscuros, negro y videos.
Fondo oscuro Videos Dark mode
07 — Imagotipo blanco (luna azul)
Versión negativa sobre azul de marca. Para usar sobre fondo #084BB9 o en presentaciones con fondo azul.
Sobre #084BB9 Presentaciones
Área de seguridad
El espacio libre mínimo alrededor del logo equivale a la altura de la letra "B" del wordmark en todas las direcciones. Ningún otro elemento puede entrar en esta zona de protección.

En el Imagotipo Full, la línea horizontal y el tagline "EFFICIENCY GROWTH" son parte integral del logo — nunca separar estos elementos del wordmark.

✅

✅

Avatar / favicon / app iconVersión 04 (lobo+luna) o versión 05 (solo lobo).
✅
Fotografía de fondoUsar lockup (recuadro blanco) o logotipo blanco. Nunca el imagotipo color directo sin contraste suficiente.
⚠️
Fondos naranja, verde o teal (secundarios)Solo logotipo blanco o isotipo simple blanco. El imagotipo de color no tiene contraste suficiente.
Usos prohibidos — nunca hacer esto
✗ Cambiar los colores
Usar solo los colores oficiales: azul #084BB9, rojo #EF2D2D y blanco.
✗ Deformar o estirar
Siempre escalar de forma proporcional, nunca distorsionar.
✗ Añadir efectos
Sin sombras, brillos, contornos, gradientes ni filtros.
✗ Rotar el logo
El logo siempre horizontal. Sin rotaciones ni inclinaciones.
✗ Bajo contraste
No usar el imagotipo de color sobre fondos de color no corporativo.
✗ Separar elementos
No separar el isotipo del wordmark salvo en casos específicos de avatar o stamp.
